# Dead Last — ไฟล์การ์ด (ตัวละครแบบ N · ป้ายห้อยคอ + สีตามหน้าที่)

การ์ดทุกใบประกอบบนหน้าเว็บจาก 3 ชั้น: ภาพในการ์ด (`art/<art>.webp` / `.png` / `.jpg`) → กรอบ (`frame-<template>.png`) → ข้อความจาก `data.csv` ตามตำแหน่งใน `template-<template>.json`
แก้ข้อความ = แก้ CSV · เปลี่ยนภาพ = เปลี่ยนไฟล์ใน `art/` · ไม่ต้องแก้โค้ด

ต้นฉบับกรอบ (`source/*.svg`) และภาพตัวอย่าง `preview.png` อยู่ในโฟลเดอร์ `dead-last-cards-v2` · ดูการ์ดทุกใบในเกมได้ที่หน้า `/preview`

## หน้าตาแต่ละแบบ

| template | การ์ด | โครง | สีหลัก |
|---|---|---|---|
| `unit` | หน่วยรบ 12 ใบ (ตัวละคร) | ป้ายห้อยคอโลหะ ภาพแปดเหลี่ยม | กรอบเขียว `#4CAF50` · ชื่อผู้เล่น ชื่อหน่วย และกรอบรอบชื่อเป็น**สีทีม** (จากคอลัมน์ `color`) |
| `defense` | DEFENSE | ระเบิดเวลา + โล่ล้อมภาพ | ส้ม `#FF8A1F` |
| `share` | SHARE | ระเบิดเวลา + ลูกศรแบ่งสองข้าง | เขียว `#43C463` |
| `steal` | STEAL | ระเบิดเวลา + รอยกรงเล็บ | แดง `#FF3B2F` |
| `grab` | GRAB ONE & GO | ระเบิดเวลา + เส้นความเร็ว | ฟ้า `#3EA8FF` |
| `gold` | ทองคำ 3 ค่า | ระเบิดเวลา + ประกายแสง + ช่องตัวเลข | เหลือง `#FFD23F` |

สีทีมที่เข้มมาก (ทีมดำ) ตัวอักษรและกรอบชื่อจะมีขอบขาวให้อ่านออก สีอื่นเรืองแสงบาง ๆ

## สิ่งที่เปลี่ยนจากชุดแรก

- การ์ด Ambush เปลี่ยนเป็น **DEFENSE**: `id` = `defense`, `template` = `defense`, `art` = `defense`
- SHARE / STEAL / GRAB แยก template ของตัวเอง (`share`, `steal`, `grab`) เพราะใช้สีกรอบต่างกัน
- การ์ดหน่วยรบมีช่องใหม่ `name_box` (กรอบรอบชื่อผู้เล่น สีตามคอลัมน์ `color`)

`player_name` (ชื่อผู้เล่น) **ไม่อยู่ใน CSV** เกมเติมให้ตอนเล่น ยาวไม่เกิน 16 ตัวอักษร

## กฎของ id

- ตัวพิมพ์เล็ก ตัวเลข และ `-` เท่านั้น ยาวไม่เกิน 40 ตัว
- **ห้ามเปลี่ยน id** เพราะกติกาใช้ id ตัดสินผล: `defense`, `share`, `steal`, `grab`, `gold-3`, `gold-4`, `gold-5`, `unit-01` ถึง `unit-12`
- ชื่อไฟล์ภาพต้องตรงกับค่าในคอลัมน์ `art` ทุกตัวอักษร (Render แยกตัวพิมพ์เล็กใหญ่)

## วิธีทำใน Google Sheet

1. File → Import → อัปโหลด `data.csv` → Replace spreadsheet
2. View → Freeze → 1 row
3. คอลัมน์ `template` และ `value` ใช้ Data → Data validation → Dropdown
4. ตัวเลขห้ามมีจุลภาค ช่องที่ไม่ใช้ปล่อยว่าง · ขึ้นบรรทัดใหม่ในช่อง `effect` ได้ (Ctrl+Enter)
5. File → Download → Comma-separated values (.csv) ตั้งชื่อ `data.csv`

## ส่วนขยายของ template ที่ใช้ในชุดนี้

`public/card.js` ของเกมรองรับส่วนขยายเหล่านี้แล้ว:

1. ช่องชนิด **`outline`**: กรอบเส้นรอบช่อง `x y w h radius width` สีจากค่าในคอลัมน์ (`#RRGGBB` เท่านั้น) · `style: "team"` = สีเข้มใส่ขอบขาว สีอื่นเรืองแสง
2. ช่องข้อความ **`colorFrom`**: ใช้สีจากคอลัมน์ที่ระบุแทน `color` (ค่าไม่ใช่ hex ใช้ `color`)
3. ช่องข้อความ **`style: "team"`** และ **`glow: true`**: เงาเรืองแสงสีเดียวกับตัวอักษร (สีเข้มมาก = ขอบขาว)
4. ช่องข้อความ **`letterSpacing`** (px บนต้นแบบ)
5. "สีเข้มมาก" = ค่าความสว่าง (WCAG relative luminance) ต่ำกว่า 0.08


ถ้ามีไฟล์ภาพชื่อเดียวกันหลายนามสกุล เกมใช้ `.webp` ก่อน แล้ว `.png` แล้ว `.jpg` — เปลี่ยนภาพใหม่ต้องแทนไฟล์ `.webp` ชื่อนั้นด้วย
